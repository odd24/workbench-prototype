# 本地工作台 MVP

一个运行在浏览器中的本地工作台。项目、问题、待办、想法和结构化信息会保存为当前电脑上的 Markdown 文件。

## 启动

在本目录执行：

```powershell
python server.py --seed-demo
```

浏览器打开：

```text
http://127.0.0.1:4173
```

`--seed-demo` 只会在没有项目时创建演示数据，后续启动可以直接运行：

```powershell
python server.py
```

也可以双击 `start-workbench.cmd` 启动。

## 数据目录

默认数据保存在：

```text
workbench-data/
├─ config/
├─ projects/
│  └─ 项目目录/
│     ├─ README.md
│     ├─ issues/
│     ├─ todos/
│     ├─ ideas/
│     ├─ infos/
│     └─ assets/
├─ ideas/
└─ .trash/
```

可用环境变量指定其他目录：

```powershell
$env:WORKBENCH_DATA_DIR = 'D:\MyWorkbenchData'
python server.py
```

## 当前已接入真实 Markdown 的功能

- 新建项目并生成项目目录和 `README.md`
- 新建问题、待办、想法和无状态的结构化信息
- 问题、待办与信息必须属于项目，想法可以不属于项目
- 从磁盘扫描并读取 Markdown 记录
- 首页展示真实待办和最近记录
- 项目问题看板
- 拖动问题卡片后自动更新 Markdown 状态
- 勾选待办后自动更新完成状态
- 标题和正文默认手动保存，支持离开时自动保存与异常退出草稿恢复
- 全局搜索标题、正文、标签、状态和优先级
- 删除接口将文件移动到 `.trash`
- 状态模板与数据目录配置
- 状态模板管理页面，可编辑名称与颜色、查看使用统计，并阻止删除正在使用的状态
- 附件上传到项目 `assets` 并自动写入 Markdown 相对路径
- 每次修改前自动保存历史版本，支持查看和恢复
- 提醒中心与浏览器桌面通知
- 每15秒检测一次外部 Markdown 修改并重新载入
- 项目归档、恢复及归档项目继续新增记录
- 项目问题、待办、想法、信息、混合看板、列表、概览和附件视图
- 信息卡片支持拖动排序和独立色条颜色；信息字段支持拖动排序、字段说明及一键插入正文
- 记录可使用自动检测或自定义的外部 Markdown 编辑器打开，并记住默认编辑器
- 全局想法收件箱与标签管理，支持使用统计并阻止删除正在使用的标签
- 回收站查看、恢复和永久删除
- Markdown 文件导入，以及由工作台内置目录浏览器选择、验证并记住位置的项目/完整 ZIP 备份导出（首次选定目录后直接导出）
- 项目附件库支持批量上传独立附件、自由分类、分类筛选与搜索，并统一查看记录附件
- 附件采用不限大小的流式上传，支持可折叠分类、分类关联标签、分类自由增删、批量改分类与确认删除
- 所见即所得、Markdown 源码和分栏编辑模式
- 优雅正文排版、四级标题、两字符列表缩进、引用与代码块编辑
- TXT 与常用编程语言代码块，可按语言和主题进行语法着色
- 正文编辑区域一键展开
- 状态、优先级、截止日期、提醒时间和标签直接编辑
- 问题、想法与待办之间转换并保留关联
- 拖放附件到编辑区域
- 从剪贴板直接粘贴截图
- 多套命名状态工作流，项目可独立选择
- 全部记录时间线
- 搜索支持类型、项目、标签、状态和优先级组合筛选
- 提醒支持打开、推迟1小时和完成
- 外部 Markdown 冲突支持保留磁盘版、工作台版或两者都保留
- 完整 Markdown 项目目录导入
- 单文件导入前预览并可修正类型、项目和标题
- 逐行冲突差异视图与可编辑合并结果
- 记录之间通过 `[[RECORD-ID]]` 建立稳定关联并可点击跳转
- 扫描并确认清理无引用附件

当前版本的桌面提醒仍需要本地工作台处于运行状态。
