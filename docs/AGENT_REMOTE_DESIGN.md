## 2. 官方规范核查

固定候选协议为MCP **2025-11-25**，不宣称最新版本，也不从stdio验收推导HTTP兼容。以下官方页面已实际读取；规范要求与本项目拟定选择分开列出。

| 官方来源 | 核查要点 | 本项目候选/待实测 |
| --- | --- | --- |
| [MCP传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports) | 单MCP端点，POST单条JSON-RPC；Accept同时包含JSON/SSE；接收通知返回202；可选会话、SSE与恢复；无效Origin403、版本不支持400 | 独立/mcp；POST可JSON或有限SSE；支持会话及SSE断流恢复，真实客户端逐项验证 |
| [MCP授权](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization) | HTTP逐请求Bearer、受保护资源元数据、受众绑定；无效令牌401、权限不足403；OAuth客户端注册方式需相互支持 | 固定issuer/resource与预注册测试客户端优先；是否可用须看目标IdP/客户端 |
| [RFC9728](https://www.rfc-editor.org/info/rfc9728/) | 定义资源元数据的发现和字段 | 资源元数据声明固定resource/authorization_servers/scopes；MCP对授权服务器列表的要求按其授权规范执行 |
| [RFC7662](https://www.rfc-editor.org/info/rfc7662/) | introspection active为必需；aud/sub/exp等并非全部必需；缓存有撤销窗口 | 本部署额外要求可验证aud/sub/exp，缺失则拒绝；初期不缓存令牌验证结果，不伪称所有标准IdP都兼容 |
| [MCP取消](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/cancellation) | 取消通知受方向/请求状态限制，初始化不可取消，完成与取消可能竞态 | 释放网络等待，不回滚已持久事务；最终以提案/回执查询为准 |
| [MCP安全实践](https://modelcontextprotocol.io/docs/2025-11-25/tutorials/security/security_best_practices) | 令牌透传、混淆代理、SSRF及会话劫持风险 | 远程令牌只向固定IdP验证，不透传到本机API；会话不替代身份，拒绝请求指定后端URL |

## 3. 候选网络与最小路由

```text
真实远程测试客户端
  → HTTPS终结/精确路由代理
  → 独立远程MCP适配进程（专用loopback端口，默认关闭）
  → 受限本机Agent HTTP（服务端配置映射的专用客户端）
  → 同一AgentService / 提案 / 历史 / 持久回执

本机网页 → 原loopback管理API → local_web完整预览和批准
本机stdio → 原Agent HTTP（保持独立可用）
```

候选端口4175只作设计示例，不是新增启动参数或实际监听。原工作台继续只监听127.0.0.1，不能把4173整体代理到网络。网关不装配第二个Repository，也不访问业务Markdown。

| 外部路径 | 候选行为 | 必须拒绝的范围 |
| --- | --- | --- |
| /mcp | 仅协议所需POST/GET/DELETE | 任意其他方法、任意子路径代理 |
| /.well-known/oauth-protected-resource/mcp | 固定资源元数据GET | 请求指定issuer/resource/URL |
| /.well-known/oauth-protected-resource | 如真实客户端发现行为需要，仅发布同一资源的合法元数据 | 通用元数据代理、任意重定向 |
| 其他所有路径 | 不转发，404 | /api/*、/、静态资源、管理、凭据、诊断、Codex登记 |

实际代理配置在选定产品/版本后生成并审查完整内容；不提供假称可用的通用反向代理命令。代理必须删除客户端伪造的Forwarded/X-Forwarded-*，仅对专用后端设置固定值；后端只信配置中明确的代理地址及固定外部origin。Origin存在时须匹配允许集；无Origin的原生客户端仍逐请求鉴权。Host、转发头及请求正文均不能选择工作空间/主体或后端地址。

## 4. 身份、授权与秘密

1. 只允许固定HTTPS issuer/introspection与元数据地址，由本机管理配置决定；TLS正常验链，禁止跳过证书验证、跨主机重定向或使用请求提供的URL。
2. 采用目标IdP支持并实测的OAuth授权码/PKCE及客户端注册方式。预注册优先只是候选；若真实客户端必须其他方式，先补充设计与SSRF/重定向校验，不能临时写密码登录。
3. introspection使用私人目录内的专用验证凭据，受限超时/响应长度；active必须严格为布尔true，aud必须包含固定canonical resource，sub是稳定非空主体，exp/nbf按实际部署契约验证；iss若返回必须与固定issuer一致。某IdP不提供这些证据时本候选不适用，不能解析未验签JWT代替。
4. 初期每次请求验证、不缓存成功身份结果。请求超时、无效JSON、凭据失效、IdP离线均失败关闭；IdP自身撤销传播延迟必须实测记录，不声称零延迟。
5. 主体键为服务端可信的(issuer,sub)，映射到一个本机专用客户端、workspace与显式kinds/scopes/项目/分类。OAuth scope再与该本机授权求交；令牌client_id/用户自报名字不能选择映射。
6. 所有远程映射客户端最低local_web，远程提案同样强制该策略；Agent自报确认不能降级，远程不能访问批准路由。批准仍只在原本机网页，异地批准属新增范围。
7. 映射新增/修改/撤销由本机CLI/UI管理，复用持久管理日志和预期版本。验证凭据、映射私钥/令牌不进Git、静态资源、工具输出或便携ZIP；远程OAuth令牌不转发为本机Bearer。

以下是部署额外要求，不能误说成RFC7662所有实现都必须返回aud/sub/exp。需要真实IdP的发行/内省样本脱敏证明，不收集真实用户长效令牌。

## 5. 传输、会话与故障契约

以下为AG-124实施前应锁定的候选矩阵，当前均未运行。

| 领域 | 候选处理 | 验收断言 |
| --- | --- | --- |
| 初始化 | 仅声明tools；协商固定版本，生成不可猜测会话ID | UTF-8、版本错误400；工具名/Schema与本机相同 |
| POST | JSON单消息，校验Content-Type/Accept；通知202无正文 | 非法/重复字段、大小超限、未初始化拒绝 |
| SSE | 每请求有限流，响应结束即终止；不广播 | 首事件/最终响应、断开与取消分离、代理缓冲关闭 |
| GET恢复 | 带Last-Event-ID只恢复本主体/会话/原流 | 他人/其他流不可重放，无恢复范围时明确失败 |
| 会话 | 绑定issuer/sub/本机client/workspace；每请求重验身份 | 缺失/过期、换主体、授权收窄均拒绝；重启重建会话 |
| DELETE | 仅结束当前会话和网络资源 | 不撤销已提交业务、不能删除正式数据 |
| 重试/断流 | 持久request_id/提案版本摘要负责幂等 | 重连或代理重试不新建第二条，超时先查原提案 |
| 取消 | 仅取消匹配方向的在途请求；已确认事务保留 | 初始化/未知请求不误取消，写后仍可查原回执 |
| 关闭远程 | 拒绝新会话/请求，停止网络资源 | 本机网页/stdio继续用；未决事务按日志恢复 |

拟定初值：每主体120请求/分钟、4个并发请求、1MiB请求；每主体最多2个SSE连接、30分钟会话寿命；重放缓存每会话最多128事件/总8MiB，失效返回重初始化/业务查询指引，不重新执行工具。introspection总时限3秒/响应16KiB；SSE网络空闲60秒发送心跳或关闭重连，不把它作为业务事务回滚时限。以上都需真实代理/客户端与资源样本校准，当前不是应用默认配置。

## 6. 威胁模型与验证点

| 攻击/失效 | 可信边界与候选措施 | 必验失败路径 |
| --- | --- | --- |
| 泄露本机管理 | 精确路由，专用监听，本机管理同源会话不外发 | 外部请求/编码路径/重写路径访问管理、静态、凭据均失败 |
| 伪造受众/主体/空间 | 固定issuer内省与aud检查，服务端主体映射和授权交集 | 跨主体/空间/错误aud、无sub/exp、用户自报client_id拒绝 |
| 令牌透传/泄密 | 远程Bearer仅固定内省；日志只脱敏结果码 | 命令行、响应、访问日志、错误栈和ZIP扫描无秘密 |
| SSRF/重定向 | 固定HTTPS端点、无通用代理、严格TLS | 请求提供URL/内省重定向/证书错误失败关闭 |
| 代理头/DNS重绑定 | 固定origin/可信代理/Host，校验Origin | 恶意Origin、伪造转发头、未信代理拒绝 |
| 会话劫持 | 会话不是授权，逐请求主体绑定 | 复用他人会话、事件游标跨流重放失败 |
| DoS/慢流 | 并发/大小/速率/连接/超时/缓存容量限制 | 超限、无穷流、IdP慢响应有界回收 |
| 批准绕过 | 所有远程提案local_web，本机批准不出网 | user_confirmed、伪造管理头/票据、放宽客户端策略拒绝 |
| 重复写/崩溃 | 同一ProposalStore日志，响应丢失查原操作 | 每阶段中断、已删除目标不重建、第三方修改不覆盖 |
| IdP失效/撤销 | 不缓存成功结果，离线拒绝新请求 | 真实撤销传播测量、验证凭据轮换、时间边界 |

仍不能防御已控制本机用户或私有网关进程的攻击者；不把本机文件或原无认证网页API描述成多租户沙箱。
