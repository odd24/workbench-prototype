# RF-001 行为与视觉基线清单

本清单配合 [`../test-fixtures/baseline-data`](../test-fixtures/baseline-data) 使用。样本必须先复制到一次性目录，不能直接写入仓库样本，也不能使用真实 `workbench-data/` 验收。

## 启动环境

```powershell
$testData = Join-Path $env:TEMP ("workbench-baseline-" + [guid]::NewGuid())
Copy-Item -Recurse test-fixtures/baseline-data $testData
python server.py --data-dir $testData --port 4174
```

浏览器打开 `http://127.0.0.1:4174`。结束后关闭服务并删除该一次性目录。

## 每套环境的检查页面

- 首页：项目、当前待办和最近记录无截断或横向溢出。
- 项目问题看板：中文长标题、标签、状态、截止日期可辨认。
- 项目待办与信息视图：多行信息字段保留换行、引号和连续空格，且只提供复制行为。
- 知识库：`维护手册` 与持久化的 `空分类` 同时显示，文档顺序保持。
- 文档阅读与编辑：标题、引用、列表、表格、代码块和 `[[ID]]` 链接不暴露非预期 Markdown 标记。
- 概念图：连接短语、两条边、箭头方向和保存的视口可恢复。
- 搜索：搜索“基线”可命中记录和文档；历史 `idea` 可读取但普通新建入口不可见。
- 空数据：使用另一个全新临时目录启动，确认空状态文案和主要操作可用。

## 状态与交互

每套环境同时检查：

- 默认、hover、键盘 focus、disabled 和 error 状态不只依赖颜色传达；
- 对话框、抽屉、下拉菜单不超出视口，遮罩和关闭操作正常；
- 保存后刷新页面，当前记录/文档内容和分类顺序仍在；
- 快速切换记录或文档时，旧请求结果不覆盖当前对象；
- 模拟外部修改后能看到刷新或冲突流程，不静默覆盖编辑内容。
