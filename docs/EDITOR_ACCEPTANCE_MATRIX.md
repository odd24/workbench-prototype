# RF-205 编辑器验收矩阵

本矩阵固定共享编辑器内核的自动与手工验收范围。所有会写入数据的项目均使用一次性 `--data-dir`；不得对真实 `workbench-data/` 执行。

## 固定契约样本

| 范围 | 样本 | 自动入口 | 结果 |
| --- | --- | --- | --- |
| 结构块 | 六级标题能力、段落、普通/编号/任务列表、引用、代码、分隔线、表格、对齐块 | `test_document_model.html`、`test_editor_blocks.html` | 通过 |
| 行内格式 | 粗体、斜体、删除线、行内代码、链接 | `test_document_model.html` | 通过 |
| 受控 HTML | `<u>`、白名单前景色/背景色、`<div align>` | `test_document_model.html`、`test_editor_blocks.html` | 通过 |
| 代码语言 | JavaScript、Python、Shell 语言标识与原始代码 | `test_document_model.html` | 通过 |
| 任务状态 | 未完成与已完成任务的 DOM、模型和 Markdown | 两个浏览器契约页 | 通过 |
| 表格 | 左/中/右对齐、转义竖线、单元格换行、表格后正文 | 两个浏览器契约页 | 通过 |
| 双编辑器 | 同一 Markdown 在记录与知识库宿主中序列化一致，保存重开无损 | `test_editor_blocks.html` | 通过 |

## 保存与外部修改矩阵

| 对象 | 场景 | 预期 | 结果 |
| --- | --- | --- | --- |
| 记录 | 自动保存后关闭、重开 | Markdown 与结构块无损，草稿清理 | 通过 |
| 记录 | 未保存内容刷新后的草稿恢复 | 用户输入恢复，保存成功后草稿清理 | 通过 |
| 记录 | 保存两版并恢复历史 | 历史项可见，恢复后磁盘与 UI 一致 | 通过 |
| 记录 | 无本地 dirty 时磁盘外部修改 | 轮询后刷新为磁盘内容 | 通过 |
| 记录 | 有本地 dirty 时磁盘外部修改 | 显示冲突，不静默覆盖 | 通过 |
| 记录 | 冲突选择磁盘版 | 载入磁盘正文 | 通过 |
| 记录 | 冲突选择工作台版 | 工作台正文写回磁盘 | 通过 |
| 记录 | 冲突选择合并结果 | 用户可编辑合并正文并保存 | 通过 |
| 知识库 | 自动保存后关闭、重开 | Markdown 与结构块无损，草稿清理 | 通过 |
| 知识库 | 未保存内容刷新后的草稿恢复 | 用户输入恢复，保存成功后草稿清理 | 通过 |
| 知识库 | 外部编辑后返回 | 无 dirty 时刷新；有 dirty 时保留当前内容并提示 | 通过 |

## 执行环境

- 日期：2026-09-16
- 数据目录：运行时生成的一次性临时目录，不记录机器绝对路径。
- 服务：`node test_editor_workflows.js` 自动选择临时端口并以 `--seed-demo` 启动、停止本地服务。
- 浏览器：Microsoft Edge 无界面模式；`test_editor_workflows.js` 通过 DevTools 协议驱动真实应用 DOM、API、`localStorage`、页面刷新和 15 秒轮询，不依赖第三方包。
- 说明：外部修改直接编辑临时目录中的 Markdown 文件；外部编辑器启动能力由既有参数数组测试覆盖，不把本机编辑器配置写入仓库。
